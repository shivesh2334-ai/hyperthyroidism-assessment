# Hyperthyroidism Assessment

Standalone browser application for hyperthyroidism assessment, pathophysiology, learning, and treatment reference.

## Run
Serve this folder with any static web server, or open index.html in a browser. No API key or build step is required.

## Deployment
Vercel deploys the main branch through its GitHub integration. Framework preset: Other. Output directory: `.`. No build or install command.

The original preview-only diagram runtime has been replaced with an accessible ordered sequence so the app remains self-contained.

Clinical content is preserved from the supplied source and has not been independently validated during deployment. Intended for clinician education and decision support.
